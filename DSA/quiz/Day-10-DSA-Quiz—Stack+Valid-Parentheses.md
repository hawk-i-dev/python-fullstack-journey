## Day 10 DSA Quiz — Stack + Valid Parentheses

Reply like:

```text
1.A
2.B
3.C
...
15.A
```

### 1. Stack follows which rule?

A. FIFO  
B. LIFO  
C. Random order  
D. Sorted order

### 2. LIFO means:

A. Last In, First Out  
B. Low Input, Fast Output  
C. Left In, First Out  
D. Last Index First Only

### 3. Stack is like:

A. A stack of plates  
B. A sorted dictionary  
C. A binary tree  
D. A database table

### 4. In Valid Parentheses, opening brackets should be:

A. Ignored  
B. Pushed into stack  
C. Deleted permanently  
D. Sorted

### 5. In Valid Parentheses, closing brackets should:

A. Match the top of the stack  
B. Match the first bracket ever opened  
C. Always return True  
D. Be added to stack

### 6. Which pair is correct?

A. `)` matches `(`  
B. `)` matches `[`  
C. `}` matches `(`  
D. `]` matches `{`

### 7. Which pair is correct?

A. `]` matches `[`  
B. `]` matches `{`  
C. `}` matches `[`  
D. `)` matches `{`

### 8. Which input is valid?

A. `([)]`  
B. `{[]}`  
C. `(]`  
D. `((())`

### 9. Why is `([)]` invalid?

A. It has no brackets  
B. It closes in the wrong order  
C. It has too many letters  
D. It is sorted

### 10. Before popping from stack, we must check:

A. If stack is empty  
B. If string is sorted  
C. If number is positive  
D. If index is even

### 11. At the end, valid parentheses require:

A. Stack must be empty  
B. Stack must contain one bracket  
C. Stack must be sorted  
D. Stack must contain all closings

### 12. For input `"()"`, output is:

A. True  
B. False  
C. None  
D. Error

### 13. For input `"(]"`, output is:

A. True  
B. False  
C. None  
D. Error

### 14. Time complexity is:

A. O(1)  
B. O(n)  
C. O(n²)  
D. O(log n)

### 15. Space complexity is:

A. O(1)  
B. O(n)  
C. O(n²)
